Hotdog Grow stores user IDs and names to show leaderboards and battle results. Account creation dates support the newcomer growth grace period. Chat IDs keep each chat's game separate. The bot stores hotdog lengths in inches, the date of the last growth, battle statistics, and daily contest winners. It does not keep a full log of battles. The database schema is available in the source repository. None of the data described above is provided to third-party organizations, except for: ➖ Russian hosting company TimeWeb, providing cloud infrastructure to run the bot; ➖ French hosting company Scaleway, providing S3-compatible storage for database backups.
