Hotdog Grow хранит идентификаторы и имена пользователей для рейтингов и результатов битв. Дата регистрации нужна для льготного периода без уменьшений. Идентификаторы чатов позволяют вести отдельную игру в каждом чате. Бот хранит длину хот-догов в дюймах, дату последнего прироста, статистику битв и победителей ежедневного конкурса. Полный журнал битв не ведётся. Схема базы данных доступна в репозитории исходного кода. Никакие из этих данных не передаются третьим лицам, кроме: ➖ российской хостинг-компании TimeWeb, предоставляющей облачные ресурсы для работы бота; ➖ французской хостинг-компании Scaleway, предоставляющей S3-хранилище для резервных копий базы данных.
